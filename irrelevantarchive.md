● 1. Create a new folder and open it in your 
terminal                                                                                                      
                                                                                                                                                           
  2. Run this one command — it does everything automatically:                                                                                              
  npm create vite@latest                                                                                                                                   
  - It'll ask for a project name                                                                                                                           
  - Choose React as the framework                                                                                                                          
  - Choose JavaScript                                                                                                                                      
                                                                                                                                                           
  3. Follow the instructions it prints at the end:                                                                                                         
  cd your-project-name                                                                                                                                     
  npm install
  npm run dev                                                                                                                                              
                  
  4. Open http://localhost:5173 in your browser                                                                                                            
                  
  That's it. You'll see a working React app. Then edit src/App.jsx to start building.                                                                      
   
  ---                                                                                                                                                      
  The files it generates (index.html, main.jsx, vite.config.js) are exactly what I created for you manually — npm create vite just does it in one step.
